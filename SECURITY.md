# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report it privately through [GitHub security advisories](https://github.com/harshaltiwari47-dot/Baaja/security/advisories/new) with a description of the issue, the affected version, and steps to reproduce it. We will acknowledge your report and keep you updated while we work on a fix.
